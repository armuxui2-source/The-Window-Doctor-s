# 💎 Flagship Case Study: The Window Doctor (UK)

**Lead Product Designer & Architect:** ARM  
**Client:** The Window Doctor (Bicester & Oxfordshire)  
**Established:** 1983 • FENSA Registered #28491  
**Year:** 2026  
**Stack:** Next.js 15 (App Router) + React 19 + Supabase PostgreSQL + Tailwind CSS + Framer Motion  

---

## 🎯 1. The Challenge (โจทย์และความท้าทายทางธุรกิจ)

- **Legacy Operations**: ธุรกิจดั้งเดิม 40 ปี พึ่งพาการรับสายโทรศัพท์และสมุดบันทึก ไม่สามารถให้บริการประเมินราคาได้ทันทีเมื่อลูกค้านอกเวลาทำการต้องการทราบราคา
- **Aggressive Market Competition**: บริษัทติดตั้งหน้าต่างระดับประเทศมักใช้วิธีบีบให้ลูกค้าเปลี่ยนทั้งกรอบหน้าต่างใหม่ในราคาสูงถึง £1,200 - £1,500+ ทั้งที่กรอบเดิมยังใช้งานได้ดี
- **Lead Leakage**: ขาดระบบติดตามข้อมูลลูกค้า (CRM Lead Pipeline) และระบบวัดผลความหนาแน่นของผู้เข้าชม (Telemetry Radar)

---

## 💡 2. The Architectural Solution (สถาปัตยกรรมและโซลูชัน)

1. **5-Stage Interactive Instant Pricing Wizard (`/quote`)**:
   - ผู้ใช้เลือกบริการ (Misted Glass, Windows, Doors, Conservatories)
   - เลือกประเภทกระจก (A++ Standard, Acoustic Noise-Reduction, Triple Glazed)
   - ปรับสไลเดอร์จำนวนบาน และกรอกรหัสไปรษณีย์เพื่อรับราคาประเมินและระยะเวลา SLA เข้าสำรวจหน้างานทันที
2. **18-Module Enterprise Admin Suite (`/admin`)**:
   - ควบคุมระบบ CRM Leads, Media Asset Library, Google SEO Engine, Coverage Towns, และ No-Code Marketing Integrations ผ่าน Sidebar ยุบ-ขยายได้ (264px / 72px)
3. **Google Page 1 Local SEO Engine**:
   - ระบบสร้าง JSON-LD Structured Data อัตโนมัติ (`LocalBusiness`, `FAQPage`, `AggregateRating`) รองรับ Rich Snippets และได้คะแนน Core Web Vitals 100%
